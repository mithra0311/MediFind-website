# 💊 MediFind – Medicine Availability and Nearby Pharmacy Finder

**Find Your Medicine. Find a Nearby Pharmacy.** 📍

## 🌿 About the Project

MediFind is a web application designed to help users find medicines at nearby pharmacies. Users can search for a medicine, select their location, and view pharmacy details and recorded stock availability before visiting.

The main aim of MediFind is to make medicine searching easier, save time, and reduce unnecessary pharmacy visits.

## ❗ Problem Statement

Finding a particular medicine can be difficult when people do not know which nearby pharmacies have it in stock. Visiting multiple pharmacies can waste time and cause inconvenience, especially when a medicine is urgently needed.

MediFind provides a convenient way to search for medicines and check nearby pharmacy information online.

## 🎯 Objectives

- 🔎 Make medicine searching simple and convenient.
- 📍 Help users identify nearby pharmacies.
- 💊 Display recorded medicine stock availability.
- 🏥 Provide pharmacy details and contact information where available.
- ⏱️ Reduce unnecessary pharmacy visits.
- 🛠️ Allow administrators to manage medicine, pharmacy, and inventory information.

## ✨ Key Features

- 🔎 **Medicine Search:** Search for medicines by name, brand, or generic name, depending on the implemented functionality.
- 📍 **Location-Based Search:** Find nearby pharmacies using a location or manually entered locality, where supported.
- 📦 **Stock Availability:** View recorded stock status, such as Available, Out of Stock, or Unknown, where supported.
- 🏥 **Pharmacy Details:** View pharmacy names, addresses, and contact details where available.
- 🔐 **User Login:** Access the application through its authentication feature.
- 🛠️ **Admin Dashboard:** Manage medicine details, pharmacy information, and inventory records.

## 🗄️ Database

The main database entities include:

- 👤 **Users:** User account information.
- 💊 **Medicines:** Medicine details.
- 🏥 **Pharmacies:** Pharmacy information.
- 📦 **Inventory:** Medicine stock quantities and availability.

Additional tables may be included depending on the implemented features.

## 🔄 System Workflow

1. Open the MediFind application.
2. Search for the required medicine.
3. Enter or select a location.
4. View nearby pharmacies and recorded stock status.
5. Check pharmacy details before visiting.

Administrators can update medicine, pharmacy, and inventory records through the admin dashboard.

## 📝 Important Note

Medicine availability depends on the latest inventory information recorded in the system. Stock information should not be assumed to be real-time unless the application is connected to a live inventory system.

MediFind helps users locate pharmacy information. The current scope does not include medicine purchasing, online payments, or delivery unless those features are implemented separately.
